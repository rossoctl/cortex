# Identify an inference server by name (#1977) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Two or more `inference-router` servers can have the same URL with different keys. Each place that needs a server's name reads the name that the router recorded, not the host.

**Architecture:** The router records `modify/routed` with `Details["server"]` on each routed request. One helper in `core/model` reads that name from an `*Invocations`. The session store, the session archive's fold, the router's history scan, the router's host table read and `Resend` all use this helper. The host stays a fallback only when exactly one server has that host.

**Tech Stack:** Go 1.26.10, module `core/` only.

**Spec:** issue rossoctl/cortex#1977 (part A1 of #1975). Read it with `gh issue view 1977 --repo rossoctl/cortex`.

## Global Constraints

- Behavior for a config where each host has one server must not change. Each existing test of such a config passes unchanged, except the tests of the deleted refusals.

- Read only `Plugin == "inference-router" && Action == modify && Reason == "routed"` with `Phase == request`. Do not read the `server` detail of `would_route`, `pinned_server_removed`, `redirect_failed`, `count_tokens_local`, `cannot_translate` or any other invocation.

- Comments and docs in ASD-STE100 Simplified Technical English. Commits use `git commit -s` and end with `Assisted-By: Claude (Anthropic AI) <noreply@anthropic.com>`.

## Decisions made in this plan

1. **One helper, in `core/model`.** `model.RoutedServer` is the only reader of the `routed` invocation. Reason: the session store cannot import the router, and four callers must apply one rule. The plugin name `"inference-router"` is a literal there, with a comment that it must equal `inferencerouter.Name`. A router test asserts the two are equal.
2. **The new table method is `LastNamedServer`.** Its `serverAt` returns `(server, known)`: `known` is true when the host has at least one server, and `server` is `""` when it has more than one. Reason: the rule needs three states for a host (no server, one server, several servers), and a two-value return can carry them.
3. **Prefix strip on a shared host when the request moves off it.** When several servers share the request's host and the chosen server is not one of them, `addressed` is `""` (as the spec says). The prefix taken off the path is then the longest `endpoint.Path` of that host's servers that is a segment prefix of the request path. Reason: with `addressed == ""` the code today strips nothing, so the shared gateway's prefix stays and the target's prefix is added in front of it.
4. **`InferenceServer` moves with `InferenceHost`.** Each request that sets `InferenceHost` also sets `InferenceServer`, to `""` when that request was not routed. Reason: a stale server name beside a new host would name the wrong server.
5. **One PR.** The estimate is about 800 counted lines.

  - `func (h InferenceHosts) LastNamedServer(agent string, exists func(server string) bool, serverAt func(host string) (server string, known bool)) (string, bool)`. For each entry of `agent`:
    1. `s.Server != "" && exists(s.Server)`: candidate `(s.Last, s.Server)`.
    2. Else `srv, known := serverAt(s.Host)`, `known && srv != ""`: candidate `(s.Last, srv)`.
    3. Else `known && srv == ""`: the entry is no evidence.
    4. Else: candidate `(s.LastUnrouted, "")`.
    The newest candidate wins. Return `(server, best > 0)`. On a tie the first entry wins, as in `LastServer`.
  - `session.SessionSummary.InferenceServer string` with tag `json:"inferenceServer,omitempty"`.
