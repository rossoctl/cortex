# agentop: quieter rows, clearer panes and a shorter key bar (#2019) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the important rows and numbers in agentop stand out, and make background traffic and general keys step back, with fewer words and fewer keys.

**Architecture:** All work is in `cmd/agentop/tui` and the agentop docs. New colors go in `styles.go`. Table cells stay plain text: color comes from the `tui/table` cell-style hook (`CellStyleFunc func(r int, row Row, col int) lipgloss.Style`, already in `table/table.go:79`, so it already gets the row index). Chrome lines are styled after every cut or fit step, as #2015 does.

**Tech Stack:** Go 1.26.10, Bubble Tea v1, Lip Gloss v1.1.0, `github.com/charmbracelet/x/ansi`, `github.com/muesli/termenv`. Add no dependency.

**Spec:** issue #2019 (`gh issue view 2019 --repo rossoctl/cortex`). Read it in full before you start a task. Where this plan and the issue differ, the issue wins, except for the items under "Decisions". The mockups named in the issue are in `~/Documents/agentop-mockups/` (local files, read-only).

## Global Constraints

- The 8 rules of the issue's "Rules that stay from #2015" section apply to every task. In short:
  1. Never cut or pad a styled string with `runewidth.Truncate`, `runewidth.FillRight` or `len`. Style after those steps. `truncToWidth`, `ansi.Truncate` and `lipgloss.Width` may run after styling.
  2. Table cells keep no ANSI. Color is added inside `tui/table` through the cell-style hook.
  3. Search highlighting keeps working over every new style: match styles win, a marked row keeps its ink, the selected row keeps its tint.
  4. A cell style sets only foreground and bold. Never `Reverse` or `Background`.
  5. Each new color is a `lipgloss.AdaptiveColor` in `styles.go`.
  6. Under the Ascii profile (what `go test` gets), keys keep their brackets, and there is no bar, chip or selection mark.
  7. No regression of more than 10% in `BenchmarkRebuildEventsTable`, `BenchmarkRebuildEventsTableTrueColor` and `BenchmarkEventsTableView` (`tui/events_rebuild_bench_test.go`).
  8. The key grammar (`docs/superpowers/specs/2026-11-19-agentop-key-grammar-design.md`, `tui/key_grammar_test.go`) holds. A `[w]` hint shows the current value (`[w] 1h`).
- Each change has a test of the new look under a forced TrueColor profile, and the test checks the plain text with `ansi.Strip`. Use the profile helpers the #2015 tests use (for example `tui/cell_styles_test.go`, `tui/styles_test.go`).
- The `lipgloss.Width` of each line is the same under Ascii and TrueColor.
- Run Go commands from `cmd/agentop` with `GOWORK=off`. Always give `gofmt` a path (`gofmt -l .`).
- While you work: `scripts/dev/go-test-shards.sh -short cmd/agentop` (about 20 s) from the worktree root. The PR gate runs the full suite.
- Commits: `git commit -s`. End each message with `Assisted-By: Claude (Anthropic AI) <noreply@anthropic.com>`. No `Co-Authored-By`.
- Out of scope: everything in #2020 (part 2). Do not add: the title without the default URL, removal of the Usage pricing note, the server name in Events `HOST`.

## Decisions (made here, with the reason)

1. **PR split.** The estimate is about 2,210 counted lines, over 2,000. The issue says to split at change 6. So P1 has changes 1-5 (T1-T5) and P2 has changes 6-11 (T6-T11), stacked on P1. Reason: the issue names this split, and T6 and T11 need T3 and T5.
2. **Gauge (T1).** `contextGauge(promptTokens, width)` returns `tierBar(promptTokens, contextWindowTokens, width) + strings.Repeat("░", width-lipgloss.Width(bar))`. `width < 1` returns `""`. `promptTokens <= 0` returns `emptyCell`. Reason: `tierBar` (`spend_tiers.go:440`) already does the 8-step eighths and the "non-zero is never empty" rule.
3. **Gauge glyphs (T1).** Remove `'▕'` and `'▏'` from `tableGlyphs` and add `'░': styleDim`. The CTX column already has kind `cellAccent` (`sessionsCellKinds`), so the fill draws accent and the track draws dim. Delete the `shortcut:` comment about `▏`.
4. **Tool-row glyphs (T3).** Add `'┗'`, `'┣'`, `'⚒'` to `tableGlyphs` as `styleDim`. Draw the subagent `│` dim the same way (add `'│': styleDim`), but first grep the tests and the other panes' cells for a `│` inside a styled cell. If one exists in another table, dim only the tool row's `│` in `eventCellStyle` instead, by a separate glyph-free cell style. Reason: the glyph map is the #2015 way to draw a second ink in one cell.
5. **Bobcoins (T2).** In `styleBandAmount` (`spend_band.go:380`), an amount with no `$` is bold, and a trailing ` Bobcoins` word is `styleMuted`. `grep` found no other currency in `colorWarn` (`spend_drawer.go`, `spend_strip.go`, `usage_*.go` have none). The test keeps that true.
6. **Key bar (T4).** New palette: `colorBarBg {Light "#F3F4F6", Dark "#1F2937"}`, `colorBarChipBg {Light "#D1D5DB", Dark "#4B5563"}`, `colorBarChipFg {Light "#111827", Dark "#F9FAFB"}`. New helpers in `styles.go`: `renderKeyBar(fitted string, width int) string` and `renderTrailingKeyBar(fitted, keys string, width int) string`. Under Ascii they return exactly `renderHints(fitted)` / `renderTrailingHints(fitted, keys)`. With color, every run has `Background(colorBarBg)` (label text `colorMuted` on it, chips `colorBarChipFg` on `colorBarChipBg`), and the line is padded with bar-colored spaces to `width` (no pad when `width <= 0`). Use them only for the LAST line of the screen: `footer.go:40`, `footer.go:136`, and the Namespaces and Pods footers in `app.go` (about lines 2589 and 2614). Modal hint lines (`clear.go`, `server_picker.go`, `edit_overlay.go`, the help overlay foot) keep `renderHints`. Reason: the issue scopes the bar to the key-hint line.
7. **One-line legend (T5).** `legend()` returns exactly this plain text, swatch colors as today: `█ tools  █ model  █ retrying  █ waiting on subagents  █ waiting on you  ┆ time cut from the axis   ▁…█ requests in flight`. The fit width is `m.width`. When it does not fit, drop whole items from the right: first `   ▁…█ requests in flight`, then `  ┆ time cut from the axis`, then the swatch items one at a time from the right. Never wrap. `timelineFixedLines` 8 → 7 and `timelineLegendLines` 2 → 1.
8. **Idle cursor row (T5, T11).** `cursorStrip` with no moment picked returns `""`. The row stays (the `\n` is still written by `renderTimeline`). T11 then puts the `timelineStatus` notes there (see 11).
9. **Quiet predicate (T6).** `func rowQuiet(ctxs []cellContext, partner map[int]int, j int) bool { return eventInactive(ctxs[j].invs) && !partnerActive(ctxs, partner, j) }` in `events_blocks.go`. `rowInactiveHidden` becomes `m.hideInactive && rowQuiet(...)` in T6, and T7 deletes it. Tunnel rows need no special case: an unbridged CONNECT has no invocations, so `eventInactive` is true, and a gate deny on it makes it not quiet. Reason: the issue asks for ONE predicate.
10. **Quiet flags (T6).** Add `quiet bool` to `eventRow` and set it where the row loop renders an exchange row (`renderEventRow` in `rebuildEventsTable`). It is a field of the value in `m.visibleRows`, so `sortEventRows` moves it with its row. Add `eventRowQuiet` to `eventRowKind`, set from `m.visibleRows[i].quiet` where `kinds` is built (`events_pane.go:466`). Change the hook to `eventCellStyle(cols []eventColumn, kinds []eventRowKind, rows []table.Row) table.CellStyleFunc`. In a quiet row every cell is `styleMuted`, except: a STATUS whose `statusGroup` is `groupError` keeps `styleError`; `—` stays dim (`dashDim`); a cell in `colDir`, `colAction`, `colPlugin`, `colMethod` or `colHost` whose trimmed text equals the same column's trimmed text in row `r-1` is `styleDim`, but only when row `r-1` is also `eventRowQuiet`. Reason: a run reads as one block only when the rows touch, and the column ids come from `cols`, so the column picker cannot move the rule.
11. **Timeline header (T11).** One line: label column (26) + axis (exactly `lay.axis.width()` columns) + gutter (`"   model  tools  tok/s"`, padded to `timelineGutterWidth`).
    - Label column: `"window "` muted, then for each `offeredWindows` index one item: current = `styleSeg.Render(" "+label+" ")` with color, `"["+label+"]"` under Ascii; other = muted `" "+label+" "`. Pad to 26. Plain text with color: `window  5m  1h  24h  all `.
    - Axis: `func axisLabels(lay tlLayout) []axisLabel` places labels; `type axisLabel struct { cell int; text string; date int; bold bool }` where `cell` is the first column of `text`, `date` is the byte length of a leading `MM-DD ` date part (0 for none), and `bold` marks the two ends. `func renderAxisLine(labels []axisLabel, w int) string` styles them: `╷` dim, date muted, end times bold, other times muted, and returns exactly `w` columns.
    - Order of placement: (a) start `╷` + `01-02 15:04` at cell 0; (b) finish `01-02 15:04` + `╷`, so the `╷` sits on cell `w-1`; (c) the gap-length and live-tail labels of today (no tick, centered as today); (d) middle times every 16 cells on non-gap cells, as `╷HH:MM`, with the date added (`╷01-02 HH:MM`) when its day differs from the day of the label placed before it. A label that touches or overlaps a placed one (keep today's one-cell gap) is dropped, never cut.
    - Time format: `15:04`, or `15:04:05` when the window span is at most 10 minutes. Reason: today's axis uses seconds there, and 16-cell labels in a 5-minute window repeat the same minute otherwise.
    - Narrow: if both dated ends do not fit with one blank cell between, use undated ends (`╷15:04`, `15:04╷`). If those do not fit, show only the undated start. If that does not fit, show nothing.
    - `timelineStatus` returns only the notes (`oldest events not shown`, `refresh failed: …`, joined by ` · `), with no range. `cursorStrip` with no moment picked returns that text muted, or `""` when there is none.
    - `timelineFixedLines` 7 → 5.
12. **Short ids (T8).** `sessionIDCell` returns the first 8 bytes of a session id (UUIDs are ASCII), no `…`. `default` and a pending bucket's agent name are not cut. `SESSION` is declared 8 wide, and the rebuild widens it to the widest cell of the listed sessions, counting ids as 8 (so `claude-code` gives 11). The `default` row is all `styleMuted` (Sessions cell style: a row whose id is `default`). Update the comments at `sessions_pane.go:37` ("SESSION is 12 at 97 columns and 14 from 100 up") and in `pending_bucket.go:31`.
13. **Key bar per pane (T9).** Remove only the general keys. New strings (`search` is `m.searchHints(m.pane)`):
    - Sessions: `[↵] drill  [u] usage  [$] spend  ` + search + (`  [esc] agents` or `  [esc] pods` as today, else nothing) + `  [?] keys  [q] quit`.
    - Events: `[b/f] page  [↵] detail  [c] columns  [u] usage  ` + search + `  [esc] back` + the notices of today + `  [?] keys  [q] quit`. (`[b/f]` stays: it is not a key a user guesses.)
    - Detail: today's line without `[↑↓] move  `. Pipeline: without `[↑↓] nav  `. Plugin detail: without `[↑↓] scroll  `. Timeline: without the `[↑↓] rows  ` hint. Namespaces and Pods: without `[↑↓/jk] nav  `. Agents: without `[↑↓] nav`, but the project label stays at the head of the line. Usage: no change.
    - Every removed key keeps working, and the `?` help of that pane lists it. Add a help row where one is missing.
14. **Two-column help (T10).** `helpTwoColumnMinWidth = 115`: each column needs keyIndent 2 + key column 12 + gutter 2 + about 40 columns of description, so `2*56 + 3`. At a 140-column terminal the body is 134 wide (two columns). At 80 it is 74 (one column). Column width `colW = (width-3)/2`. Separator: `styleDim.Render(" │ ")`. Left: the pane's group (emphasized, as today) then GO TO ANOTHER PANE. Right: ANYWHERE, MOVING AROUND THIS HELP, INSIDE THE SPEND DRAWER (when `helpGlobalGroups` returns it), THE DRILL PATH. Pad each left line with `padRight` (it uses `lipgloss.Width`). The shorter column is padded with blank lines. EVERY PANE stays one column below, at full `width`.
15. **Live check and benchmark capture against the user's service** are for a human. See "For a human after review".
